# Data attribution and licensing

The input data and derived activity series in this project originate from:

Telecom Italia, 2015, “Telecommunications - SMS, Call, Internet - MI,” Harvard Dataverse, https://doi.org/10.7910/DVN/EGZHFV.

[from BigDataChallenge contest](http://www.telecomitalia.com/tit/en/bigdatachallenge.html).

The dataset's published terms specify the Open Database License (ODbL) 1.0. Preserve attribution and the applicable share-alike requirements when distributing a derived database. See [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/) and the [publisher's dataset terms](https://dataverse.harvard.edu/dataset.xhtml?persistentId=doi:10.7910/DVN/EGZHFV).

The raw dataset is excluded from Git. `results/selected_series.csv` and other data-derived tables retain this source attribution. Third-party reference documents are excluded from Git. This notice concerns the data, not a claim of authorship over the original database or papers.
